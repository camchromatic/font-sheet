# Font Sheet

Drop in a font file and get a card that shows it off.

**Try it:** https://camchromatic.com/font-sheet/

Font Sheet makes a one-page "card" for any font: its name, the alphabet, spacing and kerning tests, every character it has, a heading and paragraph, a pangram, your own text, and a size ladder. You choose which sections appear, then save the card as a PNG or a PDF.

**Your font never leaves your computer.** Everything runs in your browser. Nothing is uploaded, there's no sign-in, and there are no trackers.

## Features
- Works with .ttf, .otf, .woff and .woff2 files.
- Turn sections on or off. Each one can have its own letter and line spacing, and can be shown light on dark.
- Characters the font doesn't have are drawn pale grey and listed.
- Card sizes for sharing: Fit to content, Square, Portrait, Story and Link preview.
- Save as PNG or as a one-page PDF.
- Dark, Gray and Light themes. Press the **?** button for tips.

## How to use it
- **Online:** open https://camchromatic.com/font-sheet/
- **On your own computer:** download `index.html` and open it in a web browser. It works offline and needs nothing else: no install, no libraries.

Then drop a font file onto the box, or click the box to choose one.

Please check a font's licence before you share cards of it publicly.
